Cross-sectional diagnostic accuracy evaluation in the Journal of Virological Methods.
Participants in Rakai, Uganda were tested by the Ugandan Ministry of Health parallel rapid
algorithm using Determine, Stat-Pak and Uni-Gold, then by EIA with western blot
confirmation as reference. Serial-algorithm performance was estimated from the same data by
reordering the tests. No PDF is held on this machine; this page is written from the
abstract.

## Relevance to project

The observation model for HIV status at the Rakai calibration site. Any HIV prevalence or
incidence target drawn from RCCS or a comparable Rakai testing programme was produced by
one of these algorithms, and this gives the sensitivity and specificity that sit between
true and measured status.

The usable figures, all against EIA plus western blot in 2,520 participants: parallel
testing 99.7% sensitivity and 99.8% specificity; serial testing with Stat-Pak as the
screening test 99.6% and 99.7%; serial testing with Determine as the screening test 97.3%
and 99.9%. Weakly reactive results occurred in 0.6% of participants.

For a model calibrated to prevalence in a population where prevalence runs in the tens of
percent, the parallel and Stat-Pak-first serial algorithms are close enough to perfect that
treating measured prevalence as true prevalence introduces error well below the sampling
noise on the target. The Determine-first serial algorithm is not: 97.3% sensitivity means
roughly 3 in 100 infections missed, which biases prevalence downward by about 3% of its
value, and matters if a target came from a programme using that ordering.

Nothing here bears on STI diagnostics, though it is a directly comparable case of an
algorithm's ordering, rather than any individual test, determining the error structure.

## Key points

Uganda's Ministry of Health permitted both serial and parallel rapid testing at the time.
In the serial algorithm a non-reactive Determine result ends testing, which is exactly
where the sensitivity is lost.

Swapping the screening test from Determine to Stat-Pak recovers serial performance to
parallel levels (99.6% against 99.7% sensitivity), so the choice of first test carries the
algorithm.

The authors note serial testing is potentially cost saving, since a non-reactive screen
consumes one kit rather than three.

## Limitations

Written from the abstract alone, so the confidence intervals, the prevalence in the tested
sample, the age and sex composition, and the handling of the 0.6% weakly reactive results
are not available here.

Serial-algorithm performance was estimated from data collected under the parallel protocol
rather than measured under serial conditions, which assumes the tests behave the same when
run in a different order and without the others' results in hand.

Test kit lots, operator training and storage conditions from 2013 Rakai. Rapid test
performance is known to vary across all three.
